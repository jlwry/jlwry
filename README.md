# Josh Lowery
PhD Biomechanics Student, McGill University
 
`[biomechanics / multi-segment foot modelling / wearable sensing]`

I'm a PhD candidate in Kinesiology and Physical Education at McGill University, working in the MOTION Laboratory. My research develops an open-source, IMU-based framework for measuring multi-segment foot kinematics with wearable sensors, validated against the Oxford Foot Model. 

More broadly, I'm interested in taking biomechanics out of the lab and building accessible, real-world tools that make movement science meaningful beyond controlled environments.
